# FlowForge

FlowForge is a workflow automation platform I'm building to explore backend architecture, asynchronous processing, and distributed systems.

## Tech Stack

- **Backend:** Java 21, Spring Boot 4
- **Frontend:** React, TypeScript, Vite
- **Database:** PostgreSQL, Spring Data JPA, Flyway
- **Messaging:** RabbitMQ
- **Development:** Docker Compose, Maven

## Current Features

- Create and retrieve workflows through REST APIs
- Activate and deactivate workflows
- Input validation and error handling
- Database migrations using Flyway
- Application health checks using Spring Boot Actuator

## Planned Features

- Configurable workflow steps
- Webhook triggers
- Asynchronous workflow execution
- Retries and failure handling
- Execution history and monitoring
- Workflow management dashboard
- Automated tests and CI/CD
